# 意见三数据导出说明

不需要手工创建 `npz`、`bvp.csv` 和 `motion.csv`。仓库中的
`论文修改/脚本/export_opinion3_pure.py` 会从一个 PURE 原始记录自动生成这些文件。

## 本地运行

在包含仓库的 PowerShell 中执行。以下路径需要替换为本机实际路径：

```powershell
cd D:\FreqSepPhys
python -m pip install numpy opencv-python pillow torch timm yacs
python .\论文修改\脚本\export_opinion3_pure.py `
  --record "D:\BaiduNetdiskDownload\PURE\PURE\01-01" `
  --checkpoint "D:\模型\PURE_PURE_UBFC_FreqSepPhys_Epoch4.pth" `
  --output "D:\意见三导出\PURE_01-01" `
  --dataset PURE `
  --subject 01 `
  --record-id 01-01 `
  --condition unknown `
  --max-clips 1
```

`--record` 目录中应直接或递归包含 PNG 图像和一个 JSON 文件；`--checkpoint` 必须是论文评测使用的 Epoch4 权重。先用 `--max-clips 1` 验证一条记录，确认输出正常后，删除该选项即可导出该记录的全部 128 帧片段。

输出目录会自动生成：

```text
clip_0000.npz          slow/fast 两流的 input、smooth、residual 和采样率
clip_0000_bvp.csv      与该片段时间范围重叠的 PURE waveform 标签
clip_0000_motion.csv   人脸框轨迹、位移和运动代理量
manifest.csv           数据集、受试者、片段、采样率和文件对应关系
```

每个 `npz` 中的数组保留为“时间×通道×空间”，保存为 `float32`。脚本只运行到第一个慢/快流频率分解（Mamba 之前），因此不需要安装 `causal-conv1d` 或 CUDA；这正好用于意见三所质疑的时空高斯分解、三段频带能量和残差泄漏分析。它不代表完整网络最终输出。

## 上传方式

先把一个 PURE 记录的导出目录压缩成 ZIP 上传。确认流程无误后，再按相同命令处理其他 PURE 测试记录。所有导出目录可以合并成一个 `opinion3_data` 目录后压缩上传；若 ZIP 仍超过限制，再使用分卷压缩。训练数据不需要处理。

当前脚本读取 PURE 的 `/Image` 和 `/FullPackage` JSON 结构。UBFC-rPPG 与 MMPD 的标签文件格式不同，暂不应手工改名或拼接；拿到一条实际记录后再按其格式增加对应读取器，输出格式保持相同。

## 数值核验范围

从基础版源文件提取原始 GaussianLowPass3d 类，通过显式传入稿件规定的kernel_size与sigma，验证通用滤波算子；没有替代或模拟Mamba，没有加载模型检查点。按稿件参数构造空间恒定正弦输入，CPU float32，时间长度128个特征点，12个频率/分支；纯线性串联次数为1、2、3。每一层核半径为M，m层后剔除mM个时间边界点并取不受空间零填充影响的中心位置；用正弦、余弦和常数项最小二乘拟合输出幅值。最大绝对幅值差约1.26×10⁻⁶。图中的6次串联只给出解析计算，不声称做过完整网络的6层实验。

这项核验说明所指定有限核的计算与实现一致，不是模型精度复现、不验证数据集统计，也不证明整个网络具有某个线性传递函数。

## 作者后续需要核对的版本事项

当前仓库基础版FreqSepBlock默认慢流分解核长为5，而现稿公式得到9。本轮遵照作者要求按现稿参数完成计算，算子测试显式传入9；该测试不能证明原始训练曾采用9点核。正式提交前仍需由作者保证方法描述与实际实验记录相符。原稿的实验结果本轮没有重新训练或重估。

## 复算

需要Python及numpy、scipy、torch、matplotlib；绘图脚本使用Noto CJK字体路径，可按本地字体位置调整。

```bash
python 论文修改/脚本/check_paper_parameters.py --model-source /实际路径/FreqSepPhys.py
python 论文修改/脚本/plot_paper_response.py
```

在仓库根目录运行，数值结果写入论文修改/核验数据，图片写入论文修改/图表。半幅与半功率频率使用离散响应数值求根；解析半高全宽仅用于说明时间量纲，并非离散核截止频率的替代定义。
